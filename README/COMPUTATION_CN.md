# 计算补测运行与计时口径

总运行步骤、路径和依赖见[运行说明](RUN_GUIDE_CN.md)。本文件只补充保留的原补测口径，不引入新版本或额外实验。

## 固定参数

- N=1000、m=50、L=10000；客户端掉线率10%、20%、30%、40%，活跃人数900、800、700、600。
- OSA、OPA、Willow、TACITA-STE四协议，每组独立执行3次，共48次；线程数保持32。
- 同进程内串行预热客户端操作3次，再串行计时20次，取算术平均。最后对3次独立执行的均值取平均。
- 20次计时操作是为了测量重复性，不表示同一联邦学习轮要求用户上传20次，也不将这些额外采样计入逻辑一轮通信量。
- 每个配置共60个计时样本，但统计上的独立重复数仍为3。暖机样本不计入均值。
- 计时含原客户端加密与消息序列化；已完成的公共参数设置不计入客户端操作时间。
- OSA/OPA轮换客户端ID；其他协议沿用原代表性客户端输入与新的随机数。采样消息不参与正式聚合。
- TACITA单用户时间为STE和KAHE两阶段采样均值之和，并非两个进程融合后的墙钟时间。
- 服务器、验证者和委员会完整执行，按原角色计时。OSA/Willow/TACITA应答40人，OPA应答34人；保留原门限规则，不在此整理中统一改写。

## 准备及运行

主包安装、构建及冒烟成功后，在整合包根目录执行：

```bash
P="$PWD/.work/OSA_Paper_Experiments_CPU_20261008"
C="$PWD/.work/OSA_Computation_Retest_20261013"
JOBS=32 bash "$C/prepare.sh" "$P"
bash "$C/run.sh" "$P"
```

prepare在补测自己的`work/`复制源码，并应用原来已经验证的采样插桩和依赖兼容处理，不改主包源码。依赖版本、校验值及目标平台功能均按原锁校验；不允许因为编译失败而跳过核验。等待`COMPUTATION_PREPARE_PASS`后才正式运行。

## 数据和图

随包历史数据位于`data/computation/`；新结果位于上述`$C/runs/`。`raw/`保留每次完整协议执行、STE/KAHE分阶段采样和资源记录。不能只复制汇总CSV后删除证据目录，否则严格校验和绘图会失败。

自动输出4张计算图：单在线用户、单应答委员会成员、服务器、服务器加验证者。不另做一批新的通信图；每次补测会检查发送量与原参考数据相符，防止计时插桩意外改变通信。

标准差保留在绘图CSV，不画误差棒；真实均值不修改。3次独立运行和60次操作样本的不同口径必须在论文描述中区分。
